# 2차 SEO 전략 검수

이 스킬은 1차 기술 검수 후 사용자의 명시적 요청이 있을 때 실행한다. 1차
검수만 끝난 상태에서는 자동으로 실행하지 않는다.

## 분석 범위

1. **검색 의도**: 정보형, 탐색형, 비교형, 거래형 의도를 분류하고 해당
   페이지가 어느 단계에 맞는지 판단한다.
2. **키워드 적합성**: 사용자가 제공한 키워드와 페이지 내용을 비교한다.
   예시는 `견적서`, `무료 견적서`, `온라인 견적서`, `견적서 작성 프로그램`
   같은 한국어 검색어다. 키워드를 임의로 확정하지 말고 근거와 추정치를
   구분한다.
3. **SERP·경쟁 분석**: 현재 검색 결과의 상위 페이지를 확인하고 제목,
   설명, 콘텐츠 범위, 구조, 신뢰 요소, CTA를 비교한다. 검색 결과를 직접
   확인할 수 없으면 경쟁 분석을 추정으로 표시한다.
4. **검색 스니펫**: title·description이 검색 의도와 클릭 이유를 전달하는지
   평가하고 2~3개의 개선안을 제시한다.
5. **전환 흐름**: 검색 유입 → 가치 이해 → 신뢰 형성 → 회원가입/사용 시작의
   단계를 점검하고 이탈 지점을 제안한다.
6. **E-E-A-T·신뢰**: 운영 주체, 문의 방법, 이용약관, 개인정보, 실제 사용
   사례, 고객 증거, 전문성 신호를 확인한다.
7. **콘텐츠 확장**: 핵심 주제에서 파생되는 랜딩 페이지, 가이드, FAQ,
   비교·사례 콘텐츠와 내부 링크 구조를 제안한다.
8. **실제 데이터**: Search Console·GA4·키워드 도구가 연결되어 있을 때만
   실제 유입·노출·CTR·순위를 사용한다. 연결되지 않았으면 데이터 부재를
   명확히 표시하고 추정치를 실제 성과처럼 쓰지 않는다.

## 분석 원칙

- 검색량, 경쟁도, 순위는 출처가 없으면 숫자로 단정하지 않는다.
- SEO 휴리스틱과 검색엔진이 확인한 사실을 별도 표기한다.
- 경쟁사 콘텐츠를 복사하지 않고 검색 의도와 사용자 문제를 기준으로 비교한다.
- 제목·문구 개선은 한국어 자연스러움과 실제 클릭 이유를 우선한다.
- 제품 페이지는 SEO 점수보다 검색 유입 후 가입·사용으로 이어지는 흐름을
  함께 평가한다.

## 2차 결과물

- 핵심 검색 의도와 대상 키워드군
- 경쟁 페이지 비교표
- 검색 스니펫 개선안 2~3개
- 콘텐츠 갭과 신규 페이지 우선순위
- 내부 링크 구조 제안
- 전환 흐름 개선안
- E-E-A-T 신뢰 보강안
- 실제 데이터 / 추정 / 미확인 항목 구분
- 30일 실행 우선순위
